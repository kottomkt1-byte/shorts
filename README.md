# AUTO SHORTS STUDIO — 로컬 자동 숏폼 스타터

**제품 광고 + 코믹 바이럴 + 감각적인 광고 + 감성 브랜딩** 4가지 카테고리의 **8종 템플릿**을 실제로 실행할 수 있는 자동 편집기 스타터입니다.

- 동영상 업로드(1~20개, 각 500MB 이하)
- 템플릿 8종 선택, 브랜드명·후킹 문구·장면별 문구 수정
- 9:16 / 30fps / H.264 MP4 출력(540×960 빠른 확인, 1080×1920 최종 출력)
- 컷 길이, 자동 배치, 템플릿별 색감과 그래픽 오버레이, 컷/디졸브 전환, 데모 BGM
- 웹에서 렌더링 진행률 확인 후 MP4 미리보기/다운로드
- 8종 템플릿은 **프로젝트가 직접 제작한 오리지널 그래픽**, 템플릿 외부 복제가 아닙니다.

## 1. 실행

**필요 환경**: Python 3.11+, FFmpeg/FFprobe가 PATH에 설치된 Windows/macOS/Linux

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.server:app --host 127.0.0.1 --port 8787
```

브라우저에서 **http://127.0.0.1:8787** 열기.

Windows FFmpeg 설치 예: `winget install Gyan.FFmpeg` (설치 후 새 터미널에서 `ffmpeg -version` 확인).

## 2. 실제로 포함된 템플릿

| 카테고리 | 템플릿 | 길이 | 스타일 |
|---|---|---:|---|
| 제품 광고 | FLASH HOOK | 18초 | 옐로/블랙 · 빠른 컷 · 강한 후킹 |
| 제품 광고 | REVIEW CUT | 24초 | 크림/그린 · 장점 3가지 · 정보 자막 |
| 코믹 바이럴 | MEME BOMB | 15초 | 핑크/라임 · 말풍선 · 강한 대비 |
| 코믹 바이럴 | POV STORY | 18초 | 블루/퍼플 · 대화형 상황극 |
| 감각적인 광고 | LUXE FILM | 24초 | 블랙/골드 · 레터박스 · 디졸브 |
| 감각적인 광고 | TRAVEL FLOW | 20초 | 스카이블루 · 여행/공간 · 디졸브 |
| 감성 브랜딩 | SLOW MOOD | 30초 | 세이지/아이보리 · 차분한 인용문 |
| 감성 브랜딩 | BRAND LETTER | 24초 | 차콜/아이보리 · 브랜드 철학 |

프리셋 수정은 `templates.json`, 실제 영상 그래픽은 `app/graphics.py`에서 합니다. 외부 제작사의 유료 템플릿을 포함하지 않았습니다.

## 3. 폴더 안내

- `app/server.py`: 업로드·렌더링 API
- `app/render.py`: FFmpeg 기반 컷 구성/그래픽 적용/음악/영상 출력
- `app/graphics.py`: 8가지 디자인별 그래픽 오버레이 생성
- `templates.json`: 8가지 길이·문구·스타일 설정
- `assets/music`: 프로젝트에서 직접 합성한 기본 데모 BGM(4종)
- `web`: 업로드 UI·템플릿 썸네일
- `uploads`, `outputs`: 로컬 실행 시 생성되는 작업 파일

## 4. 중요한 범위 및 제한

이 스타터는 **결과 MP4를 실제로 만들어 주는 동작하는 MVP**를 목표로 합니다. 컷 배치는 규칙 기반이며, **AI가 원본을 보고 인물·제품을 인식해서 베스트 컷을 선택하지는 않습니다.** 자동 음성 자막, 음악 비트 분석, 자유로운 타임라인 수정, 플랫폼별 게시 API 연결도 아직 미구현입니다.

- 데모 BGM은 코드로 생성한 간단한 음원입니다. 완성도 높은 광고 용도라면 직접 라이선스 확보한 음원으로 교체하세요.
- 사용자의 동영상에 촬영 권리·상업 이용 권한이 있는지 확인하세요. 남의 바이럴 영상을 무단으로 다운로드해 재게시하는 기능은 포함하지 않습니다.
- 쇼츠 광고·제휴 링크는 각 플랫폼의 광고 표시 및 제휴 프로그램 기준을 준수해야 합니다.
- **로컬 작업용** 서버입니다. 외부 공개 시 인증, 격리된 워커, 업로드 검사, 저장소 권한, 사용량 제한 등을 반드시 구현해야 합니다.
- 사용자가 올린 영상에 따라 결과물 미학적 완성도는 달라질 수 있습니다. AI 컷 판단·장면 분석은 다음 개발 단계에서 추가해야 합니다.

## 6. 테스트

```bash
python scripts/smoke_test.py
```

이 스크립트는 샘플 테스트 영상을 만들고 **8개 템플릿을 실제 MP4로 렌더링**하여 H.264 비디오·AAC 오디오·길이·해상도를 자동 확인합니다. 필요한 장면 길이만 임시 단축하므로 실제 템플릿의 15~30초 구성은 변경되지 않습니다.

Windows에서 한글 글꼴이 기본 경로에 없거나 다른 글꼴을 사용하려면 환경변수 `AUTO_SHORTS_FONT`에 한글 지원 TTF/OTF/TTC 경로를 설정하세요. 글꼴 파일은 프로젝트에 포함되어 있지 않습니다.
